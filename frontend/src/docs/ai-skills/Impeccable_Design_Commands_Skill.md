# Impeccable Design Commands Skill

## Overview
This skill provides 20 essential design commands that teach AI agents about typography, spacing, visual hierarchy, and other crucial design principles for creating impeccable user interfaces.

## 1. Typography Command
- Ensure consistent font hierarchy with proper sizing relationships
- Use no more than 2-3 font families per project
- Maintain appropriate line height (typically 1.4-1.6 for body text)
- Apply proper font weights for visual emphasis
- Consider legibility at all sizes and viewing distances

## 2. Spacing Command
- Implement a consistent spacing system based on a base unit (e.g., 4px, 8px, 16px)
- Use multiples of the base unit for all spacing decisions
- Apply appropriate spacing to create visual rhythm
- Ensure adequate breathing room between elements
- Maintain consistency across all components and layouts

## 3. Color Harmony Command
- Limit color palette to 3-5 primary colors plus neutrals
- Ensure sufficient contrast for accessibility (4.5:1 minimum)
- Use color purposefully to guide user attention
- Apply consistent color meanings throughout the interface
- Consider cultural implications of color choices

## 4. Visual Hierarchy Command
- Establish clear primary, secondary, and tertiary importance levels
- Use typography, color, and positioning to indicate importance
- Guide the user's eye through the interface logically
- Ensure focal points align with user goals
- Create visual pathways for task completion

## 5. Alignment Command
- Align elements to a consistent grid system
- Maintain consistent margins and gutters
- Use proximity to group related elements
- Ensure visual balance across the interface
- Apply consistent positioning patterns

## 6. Consistency Command
- Maintain identical treatment for identical functions
- Use consistent spacing, typography, and styling
- Apply uniform interaction patterns
- Ensure visual consistency across all views
- Create reusable component patterns

## 7. Contrast Command
- Use contrast to highlight important elements
- Apply sufficient contrast for readability
- Balance contrast levels throughout the interface
- Use contrast to create visual interest
- Ensure contrast meets accessibility standards

## 8. Balance Command
- Distribute visual weight evenly across layouts
- Balance text and graphical elements appropriately
- Apply symmetrical or asymmetrical balance as needed
- Ensure interfaces feel stable and harmonious
- Consider balance in both individual components and overall layouts

## 9. Proximity Command
- Group related elements together
- Separate unrelated elements with appropriate spacing
- Use proximity to indicate relationships
- Apply consistent grouping patterns
- Ensure logical information architecture

## 10. Repetition Command
- Repeat visual elements to create unity and consistency
- Use consistent styling for similar components
- Apply recurring design motifs appropriately
- Ensure repetition strengthens rather than weakens design
- Maintain variety within repetition for visual interest

## 11. Emphasis Command
- Create clear focal points for important elements
- Use visual hierarchy to guide attention
- Apply emphasis techniques consistently
- Ensure emphasis aligns with user goals
- Balance emphasized elements with surrounding content

## 12. Unity Command
- Create cohesive designs that feel like parts of a whole
- Use consistent design language throughout
- Ensure all elements contribute to overall harmony
- Apply unified styling and interaction patterns
- Maintain thematic consistency across all touchpoints

## 13. White Space Command
- Use white space intentionally to improve readability
- Apply appropriate breathing room around elements
- Ensure white space contributes to visual hierarchy
- Balance content density with white space
- Use white space to separate sections and groupings

## 14. Scale Command
- Apply appropriate sizing relationships between elements
- Use scale to indicate importance and hierarchy
- Ensure elements are sized appropriately for their function
- Maintain consistent scale relationships across components
- Consider touch target sizes for interactive elements

## 15. Accessibility Command
- Ensure all design elements meet accessibility standards
- Apply appropriate color contrast ratios
- Design for various user abilities and assistive technologies
- Consider keyboard navigation and screen readers
- Test designs with accessibility tools

## 16. Responsiveness Command
- Design for multiple screen sizes and orientations
- Apply flexible layouts that adapt appropriately
- Ensure touch targets remain usable on all devices
- Maintain visual hierarchy across different contexts
- Test designs on actual devices when possible

## 17. Functionality Command
- Ensure design serves user needs and goals
- Apply visual design to enhance functionality
- Consider user workflows and task completion
- Balance aesthetic appeal with practical utility
- Test designs with real user scenarios

## 18. Simplicity Command
- Eliminate unnecessary elements and complexity
- Focus on essential functions and content
- Apply "less is more" principle where appropriate
- Ensure interfaces feel clean and uncluttered
- Remove elements that don't serve a clear purpose

## 19. Feedback Command
- Design clear feedback for user interactions
- Apply consistent feedback patterns throughout
- Ensure feedback is immediate and informative
- Use visual, auditory, or haptic feedback as appropriate
- Test feedback mechanisms for effectiveness

## 20. Perfection Command
- Review and refine designs iteratively
- Eliminate visual glitches and inconsistencies
- Ensure pixel-perfect implementation where appropriate
- Test designs in various contexts and conditions
- Strive for excellence in every detail

## Implementation Guidelines

### When Using These Commands
- Apply commands systematically during the design process
- Reference specific commands when giving feedback
- Use commands to evaluate design decisions
- Combine commands for comprehensive design reviews
- Adapt commands to specific project requirements
