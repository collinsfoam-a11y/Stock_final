## 2024-07-17 - Icon-only Button Accessibility
**Learning:** Icon-only animated buttons (like those found in `ScreenHeader.tsx`) often lack proper accessibility labels by default. The codebase provides utility functions `getAccessibleButtonProps` and `getDecorativeIconProps` from `@/utils/accessibility` or relative equivalents which should be systematically applied to ensure components like `TouchableOpacity` and `Ionicons` are properly read by screen readers.
**Action:** When working on interactive UI elements that solely rely on icons, always check for and implement these accessibility utility wrappers. Pass meaningful and dynamic `accessibilityLabel` props down from parent components where possible.
