## 2024-05-24 - [List Rendering Optimization in React Native]
**Learning:** React Native's standard `FlatList` can suffer significant frame drops and memory issues when rendering long, complex items or paginated lists with infinite scrolling (like search results). The `VirtualList` component (which wraps `@shopify/flash-list`) is vastly superior for these use cases but requires a precisely calculated `estimatedItemSize` to function optimally.
**Action:** When working with potentially long lists in this codebase (especially in search or data tables), always prefer `VirtualList` over `FlatList`. ## 2024-07-25 - [Virtualization Overhead Optimization in React Native]
**Learning:** Using virtualized lists like `FlatList` with `scrollEnabled={false}` is a performance anti-pattern. It incurs the initialization and memory overhead of a virtualized list without gaining any of the off-screen element recycling benefits, because the scrolling logic is outsourced to a parent container.
**Action:** When nesting lists inside `ScrollView`s that don't need independent scrolling, replace the `FlatList` with a standard `View` that uses `.map()` to render items. Ensure stable keys (e.g., `<React.Fragment key={item.id}>`) are preserved during the refactor.
