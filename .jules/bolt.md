## 2024-05-24 - [List Rendering Optimization in React Native]
**Learning:** React Native's standard `FlatList` can suffer significant frame drops and memory issues when rendering long, complex items or paginated lists with infinite scrolling (like search results). The `VirtualList` component (which wraps `@shopify/flash-list`) is vastly superior for these use cases but requires a precisely calculated `estimatedItemSize` to function optimally.
**Action:** When working with potentially long lists in this codebase (especially in search or data tables), always prefer `VirtualList` over `FlatList`. ## 2024-05-27 - [MongoDB Aggregation Optimization with $facet]
**Learning:** Sequential `count_documents` and `aggregate` queries on the same collection for statistics dashboards cause significant database round-trips and I/O latency. Combining these separate metric aggregations into a single `$facet` pipeline reduces multiple queries down to a single network call, yielding major performance gains.
**Action:** When implementing or refactoring dashboard/statistics endpoints (e.g. `get_statistics`) that compute multiple distinct metrics over the same dataset, consolidate the sequential queries into a single aggregation pipeline using the `$facet` stage.
