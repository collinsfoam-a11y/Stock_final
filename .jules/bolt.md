## 2024-05-24 - [List Rendering Optimization in React Native]
**Learning:** React Native's standard `FlatList` can suffer significant frame drops and memory issues when rendering long, complex items or paginated lists with infinite scrolling (like search results). The `VirtualList` component (which wraps `@shopify/flash-list`) is vastly superior for these use cases but requires a precisely calculated `estimatedItemSize` to function optimally.
**Action:** When working with potentially long lists in this codebase (especially in search or data tables), always prefer `VirtualList` over `FlatList`. ## 2026-07-16 - Avoid Virtualized Lists with scrollEnabled={false}
**Learning:** In React Native, using virtualized lists like `FlatList` or `FlashList` with `scrollEnabled={false}` introduces virtualization overhead (and potentially weird rendering bugs) without actually providing any virtualization benefits, since all items are rendered at once to fit the parent `ScrollView` or container. This is a common performance anti-pattern.
**Action:** When a list needs to shrink-wrap its content (e.g., inside a `ScrollView` where `scrollEnabled={false}` is used), just `.map()` over the data array directly and render standard `View` components instead of using `FlatList` or `FlashList`.
