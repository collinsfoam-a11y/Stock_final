## 2024-05-24 - [List Rendering Optimization in React Native]
**Learning:** React Native's standard `FlatList` can suffer significant frame drops and memory issues when rendering long, complex items or paginated lists with infinite scrolling (like search results). The `VirtualList` component (which wraps `@shopify/flash-list`) is vastly superior for these use cases but requires a precisely calculated `estimatedItemSize` to function optimally.
**Action:** When working with potentially long lists in this codebase (especially in search or data tables), always prefer `VirtualList` over `FlatList`. ## 2024-11-20 - [Concurrent query fetching for Report Generation]
**Learning:** Sequential `await` statements for independent read-only MongoDB queries across disparate collections (like fetching `activity_logs`, `login_history`, and `audit_logs` in a loop) introduce a massive I/O performance bottleneck for generated reports.
**Action:** When implementing data fetching that pulls from multiple distinct collections without interdependent filtering, use `asyncio.gather()` to batch the queries concurrently. This effectively bounds the overall execution time to the duration of the slowest single query rather than the sum of all queries, drastically improving performance.
