## 2026-06-06 - MongoDB Query Consolidation
**Learning:** Sequential calls to `count_documents` and `aggregate` on the same MongoDB collection create severe network overhead (e.g., 6-9 round-trips for a single statistics request), which is a common bottleneck in reporting APIs built with motor.
**Action:** Consolidate multiple metrics queries into a single aggregation pipeline using the `$facet` operator to gather counts, groupings, and sorted lists in a single database round-trip. Handle the resulting `$facet` empty state safely (e.g., extracting values conditionally since empty `$count` returns `[]`).
