## 2024-05-24 - [List Rendering Optimization in React Native]
**Learning:** React Native's standard `FlatList` can suffer significant frame drops and memory issues when rendering long, complex items or paginated lists with infinite scrolling (like search results). The `VirtualList` component (which wraps `@shopify/flash-list`) is vastly superior for these use cases but requires a precisely calculated `estimatedItemSize` to function optimally.
**Action:** When working with potentially long lists in this codebase (especially in search or data tables), always prefer `VirtualList` over `FlatList`. **Learning:** React Native's `FlatList` has several legacy props (`removeClippedSubviews`, `initialNumToRender`, `maxToRenderPerBatch`, `windowSize`, `getItemLayout`) that were originally intended for performance but are now effectively superseded by `VirtualList` (powered by `@shopify/flash-list`). **Action:** Always fully migrate away from `FlatList` legacy props when switching to `VirtualList`, explicitly defining `estimatedItemSize` instead, to guarantee maximum scrolling performance without conflicting configurations.
