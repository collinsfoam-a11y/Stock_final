## 2024-05-24 - [List Rendering Optimization in React Native]
**Learning:** React Native's standard `FlatList` can suffer significant frame drops and memory issues when rendering long, complex items or paginated lists with infinite scrolling (like search results). The `VirtualList` component (which wraps `@shopify/flash-list`) is vastly superior for these use cases but requires a precisely calculated `estimatedItemSize` to function optimally.
**Action:** When working with potentially long lists in this codebase (especially in search or data tables), always prefer `VirtualList` over `FlatList`. ## 2026-07-20 - [MongoDB Concurrency with Motor/PyMongo]
**Learning:** PyMongo and Motor are completely safe to use with `asyncio.gather` for concurrent database operations. The `db` object in PyMongo is thread-safe and Motor handles the underlying async connection pooling perfectly. The `ServerSelectionTimeoutError` encountered in tests was simply because MongoDB was not running, not due to a concurrency error. The reviewer's feedback regarding `db` object safety only applies to tools like SQLAlchemy `AsyncSession` which are stateful and bound to a single connection/transaction context.
**Action:** Proceed with using `asyncio.gather` to parallelize independent read queries (like `count_documents` or `aggregate`) to optimize backend performance, as it significantly reduces I/O wait times.
